# 小葉週報 — 3月27日（五)

標題：從學生到老師——讓團隊透過AI輔助成為英雄團隊
本週在AI推動上，吸收上次課堂的經驗，不做艱深難懂的教學，透過日常工作會使用做的事情，如：加魚、查找競品規格、MongoDB託管服務有哪些、週四策略會議的匯報......等來進行NotebookLM與AI Agent Skill，透過實際演練讓所有職能的成員實際體會AI的強大。
但在非程式職能的程式教學上，卡在「簡單易懂」與「知識深度」的取捨，發現自己習慣從興趣與經驗出發，較少針對被動使用者設計引導。
我體會到開發與教學的核心都在「目的性」，程式設計要先有興趣有感非程式職能的才會願意學。過去自己成長歷程強調邏輯演算法解題，打了扎實的底子，但未必適合所有人，這也呼應「武功高手不一定會教武功」。未來需要區分研究與教學，從需求出發設計引導，讓程式邏輯的設計概念也能普及化到各個職能。
我在上完課後也有訪問學生「程式設計要扎根一年的訓練讓人覺得難以堅持」，「用VibeCoding來入門程式變簡單，但是實際運作上會不了解有哪些工具能用」，「對於用Agent Skill製作H5網頁遊戲是覺得很開心有成就感」，我也在這邊去思考，我的課程要怎麼改變跟調整能讓更多人了解，最後讓小刀也能無痛學習。
