# 管理日誌

魚機組全員管理日誌存放處。每人每天一檔，自動從 Telegram 群組 topic 12 收錄。

## 目錄結構

```
management-log/
├── README.md          ← 本檔案
├── index.md           ← 日誌索引（自動維護）
└── YYYY-MM-DD/
    └── <人名>.md      ← 每人每天一檔
```

## 使用方式

在 Telegram 群組的「管理日誌」topic 中：
- 直接發送訊息 → 自動存檔
- 「修改」→ 修改自己的日誌
- 「刪除」→ 刪除自己的日誌
- 「查看」→ 查看自己的歷史日誌

## 權限
- 每人只能管理自己的日誌
- 管理員（小葉）可查看全部
