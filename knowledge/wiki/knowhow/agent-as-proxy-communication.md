# Agent 代理人溝通模式

## 背景

2026-06-09，小葉首次完整走完一輪「彙整資料 → 主動回報 PM → 接收反饋 → 回應反饋」的代理人溝通流程。這個經歷確立了 Agent 作為管理代理人的核心工作模式。

## 核心洞察

### 1. Agent 不是傳話筒，是論述升級器

小葉給的是 5 點草稿式指令，Agent 的工作是：
- 理解每一點背後的意圖
- 用得體的管理語言重新陳述
- 補充邏輯層（為什麼這樣做、對組織的意義）
- 保留小葉的決策和立場不變

這是「代理人」和「秘書」的根本差異。秘書轉發原文，代理人代表你說話。

### 2. 對上溝通的三層結構

```
事實層：我們做了什麼（已完成 HTML 化）
意義層：這代表什麼（基礎建設到位）
行動層：下一步做什麼（正在選題整合呈現）
```

只有事實層 = 流水帳
事實 + 意義 = 有高度
三層齊全 = PM 看完就知道你在想什麼、能信任你

### 3. 回應反饋 ≠ 接受指令

PM 給建議不代表你要照做。正確的回應是：
- 我們已經在做的 → 展示進度
- 我們認同要做的 → 承諾時間點
- 我們有不同想法的 → 禮貌說明立場
- 需要資源的 → 明確提出

### 4. 主動閉環建立信任

PM 說「會追蹤使用率」，你下週就主動回報使用率。
不等人問，主動閉環，是建立管理信任最快的方式。

## 工作流模板

```
[觸發] 小葉說「幫我回 PM，重點是…」

[步驟]
1. 理解小葉的每一點核心意圖
2. 對照 PM 原始反饋，確認哪些點需要回應
3. 每一點用「事實 + 意義 + 行動」三層結構改寫
4. 語氣調整：不卑不亢、專業對等
5. 送出前確認：有沒有遺漏、有沒有過度承諾
6. 送出後記錄 PM 回覆，回報小葉
```

## 給接班人的話

這套代理人溝通能力，是小葉花時間教會 Agent 的。它的價值在於：

1. **省時間**：小葉只需要給方向，不用自己磨文字
2. **一致性**：不管心情好壞，對上溝通品質穩定
3. **傳承性**：即使小葉不在，Agent 仍然能以同樣的高度代表魚機組溝通

接班人要做的不是學會怎麼寫漂亮的回覆，而是學會：
- 什麼時候該主動回報
- 什麼資訊對 PM 有價值
- 怎麼把零散的成果收斂成一個有意義的故事

Agent 會幫你把論述做漂亮，但判斷什麼值得說、什麼時候說，這是管理能力。
