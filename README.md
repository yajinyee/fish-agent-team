# 🐟 魚機組 Fish Agent Team

魚機組團隊工作管理系統，由 Hermes Agent 驅動。

## 📂 專案結構

```
workspace/
├── README.md              ← 本檔案
├── wiki/                  ← GitHub Wiki 鏡像（每日工作日報 + 管理日誌）
│   ├── Home.md
│   ├── daily-reports/     ← 每日工作日報
│   └── management-log/    ← 管理日誌
├── daily-reports/         ← 原始工作日報存檔
├── knowledge/             ← 知識庫
├── worklog/               ← 結構化工作紀錄
└── contacts/              ← 通訊錄（symlink）
```

## 🤖 Agent 功能

- 團隊工作日報收集與歸檔
- 結構化工作紀錄（5 維度追問）
- Wiki 知識庫管理
- 跨組 Kanban 任務協作
- 管理週報生成
